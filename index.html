ABOUT THE PROJECT

Built to explore AI.

BrainScan AI is an educational image-classification project exploring how machine learning can be applied to brain scan imagery through an accessible interface.

🧠

What is BrainScan AI?

BrainScan AI is an image-classification prototype. A machine-learning model is trained using labelled examples and then evaluates new images according to patterns it learned during training.

⚙️

How does it work?

When an image is uploaded, the trained model analyzes the image and produces a probability for each of its four learned classes. The class with the highest probability becomes the displayed prediction.

💻

Technology

AI: Google Teachable Machine
Runtime: TensorFlow.js
Interface: HTML, CSS & JavaScript
Mobile: MIT App Inventor WebViewer
🎯

Project Objective

The project demonstrates a complete AI workflow: training an image-classification model, connecting it to a web interface, accepting new images and presenting the model's output in an interactive way.
