ABOUT THE PROJECT

AI meets neuroscience.

BrainScan AI is an educational artificial-intelligence project demonstrating how image classification can be used to organize brain images into predefined categories. The model was trained separately using Google Teachable Machine and integrated into this interactive web interface.
