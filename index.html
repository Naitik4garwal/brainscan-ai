ABOUT THE PROJECT

About BrainScan AI

BrainScan AI is an educational artificial intelligence project designed to demonstrate how image classification can be applied to brain scan images.

🧠

What is BrainScan AI?

BrainScan AI is an image-classification prototype. A machine-learning model is trained using labelled brain scan images and then used to classify new, previously unseen images.

⚙️

How Does It Work?

When an image is uploaded, the trained model analyzes visual patterns in the image and assigns probabilities to the classes it has learned. The class with the highest probability is displayed as the prediction.

💻

Technology Used

AI Model: Google Teachable Machine
Model Runtime: TensorFlow.js
Web Interface: HTML, CSS & JavaScript
Mobile Application: MIT App Inventor
🎯

Project Purpose

The purpose of this project is to explore the use of artificial intelligence and image classification in medical-imaging research. It demonstrates the process from training an AI model to deploying it through a user-friendly application interface.

🤖

About the AI Model

The classification model was trained using labelled image examples. During prediction, the model evaluates the uploaded image and produces a probability for each learned class. The displayed confidence represents the model's calculated probability for its prediction.

⚠️

Important Limitation

BrainScan AI is an educational and research prototype. Its predictions should not be interpreted as a medical diagnosis. Real clinical diagnosis requires qualified healthcare professionals, appropriate medical imaging protocols, and clinical evaluation.

Educational Research Project
BrainScan AI provides AI-based image classification for educational and research purposes only. It is not a medical diagnostic tool.
